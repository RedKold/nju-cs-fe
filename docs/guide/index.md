# 资料库使用指南

这个仓库面向南京大学计算机金融实验班的在读学生，目标是把课程学习、推免、
出国三条线上反复被问到的问题沉淀下来，让下一届不用再从聊天记录里翻答案。

## 内容怎么组织

| 板块 | 内容 | 适合谁看 |
| --- | --- | --- |
| [课程资料](/courses/) | 课程地图、学习重点、考核方式、资料索引 | 全体，尤其低年级 |
| [推免](/postgrad/) | 资格、时间线、材料、面试 | 大三及以上 |
| [出国](/abroad/) | 申请时间线、选校、文书、语言考试 | 大二下学期起 |
| [实习与就业](/career/) | 方向介绍、实习节奏、技能栈 | 大二及以上 |
| [资源区](/resources/) | 课件、真题、模板的下载链接 | 全体 |

## 三条建议的阅读顺序

**大一** 先看[培养方案](/guide/curriculum)，搞清楚学分构成和课程先后关系，
然后按学期去[课程资料](/courses/)找对应科目。

**大二** 看[四年时间线](/guide/roadmap)，确定自己是走推免还是出国，
两条路的准备动作从大二下学期就开始分叉。

**大三** 直接进[推免](/postgrad/)或[出国](/abroad/)板块，按时间线倒排自己的待办。

## 文档约定

- 页面里出现 `待补充` 或 `⚠️ 待核对` 的地方，说明这一条还没有经过验证，请不要当结论用。
- 经验性内容会标注作者和年份，年份越新参考价值越高。
- 涉及硬性规定（名额、学分、资格线）只写"以官方文件为准"，并给出来源链接。

## 怎么贡献

任何同学都可以补充内容，不需要先问过谁。仓库开启了 PR 流程，
改动会先提交到分支，经审阅后再合并进 `main`，合并后自动部署上线。

完整流程见 **[如何贡献](/guide/contributing)**。最省事的用法是把它交给 Makefile：

```bash
make install                      # 首次装依赖
make branch NAME=feat/夏令营经验    # 从最新 main 建分支
make dev                          # 边写边预览
make pr                           # 检查 + 推送 + 给出 PR 链接
```

也欢迎你聪明地使用 agent 帮忙整理和校对。

几条硬规矩：

- **不要把大文件提交进 git**。PDF、录屏、压缩包一律走[资源区](/resources/)的外部链接，
  仓库只保留文字和链接。
- 不要上传他人未授权的版权材料（教材扫描版、付费课程录屏等）。
- 涉及具体老师的评价请就事论事、对事不对人。
