# 培养方案与课程地图

> ⚠️ **待核对**：本页的课程清单和学分构成是根据同类专业的通用结构整理的框架，
> **不是**本届培养方案的原文。请按教务系统里你入学年份对应的培养方案逐条填写。

## 专业定位

计算机金融实验班是计算机科学与技术同金融学的交叉培养方向，目标是让学生同时具备
扎实的编程与数学功底，以及理解金融市场与定价模型的能力。

因此在课程上会有三条并行的主线，而不是单一学科。

## 三条课程主线

### 数学与统计（地基）

决定你后面能走多远的一条线。金融里的定价、计算机里的机器学习，最后都落在这里。

数学分析、高等代数、概率论、数理统计、随机过程、数值分析、常微分方程、运筹优化等。

### 计算机（工具）

程序设计、数据结构与算法、计算机组成、操作系统、计算机网络、数据库、机器学习等。

### 金融与经济（场景）

微观经济学、宏观经济学、金融学、公司金融、投资学、计量经济学、衍生品定价、固定收益等。

## 选课建议

**优先保证前置课。** 数学分析没学好直接上随机过程，大概率两头都学不明白。

**大二下再决定方向。** 这个学期同时接触了计算机和金融的核心课，
是判断自己更偏工程、偏研究还是偏市场的好时机。

**选修课服务目标。** 走推免就选能出成绩、能跟老师做科研的课；
走出国就选有项目输出、能写进 CV 的课。
