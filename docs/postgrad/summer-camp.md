# 夏令营

夏令营是推免里 offer 最集中的一批，通常也是准备时间最紧的一批。
大三下学期才第一次听说，往往已经错过报名。

## 时间节奏

```text
3 月    部分院校开始发布夏令营公告
4-5 月  公告集中发布，开始投递
5-6 月  报名截止、材料审核、发放入营通知
6-8 月  夏令营集中举办
8-9 月  发布优秀营员名单（部分院校即等于预录取）
```

> 具体日期各院校差异很大，从 3 月到 7 月都可能截止，必须逐个查。

## 投递策略

夏令营可以同时投多所，但**时间冲突是常态**，需要提前取舍。

建议按三档组合：

- **冲刺**：排名和背景略高于自己水平的院校，投一两所
- **匹配**：和自己水平相当，这是主要战场，投三到五所
- **保底**：有较大把握的院校，投一到两所

投递时把每个营的时间、材料截止日、考核形式记在表格里，
这张表建议直接维护在本仓库，供下一届参考。

> ⚠️ **待补充**：历年各院校夏令营时间表与考核形式汇总。

## 报名材料（常见清单）

- [ ] 个人简历
- [ ] 个人陈述 / 研究计划
- [ ] 成绩单与专业排名证明（通常是教务系统导出后盖章）
- [ ] 推荐信（一般 2 封，部分院校要求副教授以上）
- [ ] 英语成绩证明（四六级 / TOEFL / IELTS）
- [ ] 获奖证书、论文、项目证明
- [ ] 身份证与学生证复印件

## 考核形式

计算机金融方向常见的组合：

| 形式 | 考什么 | 准备重点 |
| --- | --- | --- |
| 笔试 | 数学（数分、线代、概率统计） | 复习主干课，重推导 |
| 机试 | 数据结构与算法 | 提前刷题，熟悉在线判题 |
| 面试 | 专业课 + 科研经历 + 英语 | 能讲清自己做过的项目 |
| 综合面试 | 读研规划、沟通表达 | 想清楚为什么读、想做什么方向 |

很多院校是"笔试刷人、面试定结果"，笔试不过直接失去面试机会，
所以**数学和算法要提前一个月开始复习**。

## 一些经验

- **6 月到 7 月会很忙。** 多个营撞在一起时，优先保证匹配档和保底档，
  不要为了冲刺档放弃所有退路。
- **优秀营员不等于录取。** 有的院校给的只是"优先考虑"，
  最终还要在推免系统里走流程，要问清楚效力。
- **面试会追问细节。** 简历上写的每一个项目都可能被深挖，
  写不熟的东西不如不写。
- **结束后立刻复盘。** 当天记下被问到的问题，后面几场会重复出现。
