# 面试经验

面试通常 10～20 分钟，要在这段时间里让老师相信两件事：
**你的基础是扎实的**，以及**你确实想读这个方向**。

## 问题一般从哪来

### 数学与专业课

最高频的部分。计算机金融方向尤其爱问：

- 概率论：条件概率、条件期望、常见分布的期望方差、大数定律
- 数理统计：估计方法、假设检验的逻辑
- 线性代数：特征值、秩、正定、矩阵分解的几何意义
- 微积分：中值定理、泰勒展开、极值
- 金融：CAPM 的假设与含义、无套利定价的基本思想、期权的基本性质
- 计算机：数据结构选型、时间复杂度、进程与线程、HTTP 与 TCP

准备方式和期末复习不同：**要能口头讲清楚**，而不是能写出证明。
建议对着白板或纸，把每门课的核心概念讲一遍给自己听。

### 科研与项目

老师会顺着简历往下问，常见追问链：

```text
这个项目的目标是什么？
  → 你为什么选这个方法？
    → 这个方法的核心思想是什么？
      → 如果换成另一个方法会怎样？
        → 你自己在其中的贡献具体是哪部分？
```

准备时把每个项目都按这条链过一遍，尤其是"为什么这样选"这一层。

### 英语

形式可能是英文自我介绍、读一段英文材料并翻译，或用英文回答专业问题。
提前准备一段 1 分钟的英文自我介绍，练到不用背稿也能说顺。

### 读研规划

"为什么读研""想做什么方向""为什么选我们学校"这类问题，
考察的是你有没有认真想过。回答要具体，避免空话。

## 高频问题清单

面试前把下面这些问题都写成一句话答案：

- [ ] 一分钟自我介绍（中英文各一版）
- [ ] 你最有成就感的一个项目，遇到过什么困难
- [ ] 你最喜欢的一门课，为什么
- [ ] 讲一个你熟悉的概率论概念
- [ ] 讲一个你熟悉的算法，以及它的复杂度
- [ ] 你了解我们这个方向的哪些研究
- [ ] 为什么选择读研而不是工作
- [ ] 你的缺点是什么

## 面试后的复盘模板

每场结束后当天写下来，这个模板可以直接复制：

```markdown
### 学校 / 学院 / 日期

**形式**：线上 / 线下，几位老师，多长时间

**被问到的问题**
1.
2.

**答得不好的地方**
-

**下次要改进的**
-
```

> **待补充**：欢迎把各院校往年的面试真题贴进来，
> 注明学校、年份和考核形式。
