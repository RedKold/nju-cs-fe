# 推免总览

推免（推荐免试攻读研究生）是不参加统考、凭本科阶段表现拿到研究生录取资格的路径。
对计算机金融方向来说，它同时决定未来几年做什么方向、跟哪位导师。

## 三条路径，一个系统

推免录取按时间分三批，很多人三批都会参加：

| 阶段 | 时间 | 特点 |
| --- | --- | --- |
| [夏令营](/postgrad/summer-camp) | 大三暑假（6～8 月） | offer 最多，竞争最激烈 |
| 预推免 | 大四上（9 月） | 夏令营没拿到满意结果时的主要机会 |
| 九推 | 大四上（9 月下旬起） | 在推免系统里走正式流程，名额可能有剩余 |

无论走哪条路，**最终的录取确认都要在教育部推免服务系统里完成**，
没有在系统里确认，前面的口头承诺都不作数。

## 时间线

```text
大三上     刷绩点、进课题组、确定目标方向
大三下 3月  陆续关注各校夏令营公告
大三下 4-6月 准备材料、联系推荐人、集中投递
大三暑假 6-8月 参加夏令营，笔试 / 面试 / 机试
大四上 9月   预推免报名与考核
大四上 9月下旬 推免系统开放，填报志愿、接收复试、确认待录取
大四上 10月  完成录取，联系导师
```

> 具体日期每年会有变动，以推免服务系统和各院校研究生院公告为准。

## 先看什么

如果你还在大一大二，先看[政策与资格](/postgrad/policy)，
搞清楚名额怎么算、排名怎么排，这决定你接下来两年该把精力放在哪。

如果你已经大三，直接看[材料准备](/postgrad/materials)，
按清单倒排时间。
