# 什么是推免

**推免**（推荐免试）是中国高校选拔优秀应届本科毕业生免试参加研究生初试、直接进入复试并录取的制度，俗称“保研”。 它允许符合条件的本科生无需参加全国硕士研究生统一考试初试，通过学校推荐和招生单位复试即可读研。

对于计金班的同学来说，这是比考研更早的一次决定自己要修习什么方向（最简单来分，计算机or金融）的机会。


为了避免重复工作，本wiki更多提供来自计金学长的个人经验贴，对于更泛用的推免相关知识，可以阅读[南哪指南-推免与保研介绍](https://www.yuque.com/greatnju/q-a2.0/nm2p8n45ck06a4kh)
