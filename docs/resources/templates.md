# 模板

可以直接复制使用的文档模板。这些模板和[材料准备](/postgrad/materials)里的
说明配套，推免和出国两边通用。

## 简历模板

```markdown
# 姓名
电话 | 邮箱 | GitHub / 个人主页

## 教育背景
学校 · 专业 · 入学时间 - 毕业时间
专业排名：X / N      GPA：X.XX / 4.0
核心课程：课程 A（95）、课程 B（92）
英语成绩：CET-6 XXX / TOEFL XXX

## 科研经历
**项目名称** | 导师姓名 | 起止时间
- 做了什么：一句话说清问题
- 用了什么方法：技术栈与关键思路
- 结果：量化产出（准确率提升 X%、论文 / 报告、耗时从 A 降到 B）

## 实习经历
**公司 · 岗位** | 起止时间
- 职责与产出，同样写结果不写职责

## 项目经历
**项目名** | 技术栈
- 解决什么问题、你的贡献、最终效果

## 获奖情况
- 奖项名称（级别，年份）

## 技能
- 编程语言：
- 工具与框架：
- 语言能力：
```

## 个人陈述模板（推免 / 出国通用）

```markdown
## 第一段：动机
从一个具体的经历切入，说明你对这个方向的兴趣从何而来。
不要写"从小就对计算机感兴趣"这类无信息量的话。

## 第二段：能力
用课程、科研、实习证明你有基础。挑最有说服力的两段展开，
写清你具体做了什么、遇到什么问题、怎么解决的。

## 第三段：匹配
为什么是这个项目。写具体的课程名、实验室或导师方向。
这一段的针对性越强，越能看出你认真做过功课。

## 第四段：规划
短期想研究什么，长期想做什么。具体、可检验，避免空话。
```

## 套磁信模板

发给目标导师的第一封邮件。**保持简短**，老师每天收很多信。

```text
主题：关于 XX 方向读研的咨询 —— 姓名 / 学校 / 专业

尊敬的 X 老师：

您好。我是 XX 大学 XX 专业的大三学生 XXX。

我读了您关于 [具体论文或方向] 的工作，对 [某个具体问题]
很感兴趣，尤其是 [你的具体理解或疑问]。

我目前 [一句话说明背景：成绩排名、相关课程、科研经历]，
希望申请贵组的 [硕士 / 博士]，不知您今年是否还有名额。

附件是我的简历和成绩单，期待您的回复。

顺颂时祺
XXX
```

几条注意事项：

- **一定要读过对方的工作再发。** 群发模板信老师一眼就能看出来。
- 一次只联系一位老师，收到明确拒绝后再联系下一位。
- 一周没回复可以礼貌跟进一次，再没回复就放弃。
- 附件用 PDF，文件名写成 `姓名-学校-简历.pdf`。
