# 选校与文书

## 选校

不要只看综合排名。真正决定体验的是这几项：

| 维度 | 要看什么 |
| --- | --- |
| 项目方向 | 课程偏理论还是偏就业，有没有你感兴趣的方向 |
| 就业情况 | 往届去向、地理位置、当地产业 |
| 费用 | 学费加生活费总额，有没有奖学金或助教机会 |
| 学制 | 1 年还是 2 年，能否实习 |
| 录取难度 | 参考往届同背景同学的录取情况 |

### 分档方法

列出 8～12 所，按三档分配：

- **冲刺** 2～3 所：背景略差一点，但值得一试
- **匹配** 4～6 所：主要目标
- **保底** 2～3 所：有较大把握

### 信息从哪来

- 项目官网的课程表和毕业要求（最权威，一定要看）
- 往年录取数据与论坛经验
- 直系学长学姐——问他们"如果重来会怎么选"

> ⚠️ **待补充**：本专业历年录取结果表（学校 / 项目 / 年份 / 背景 / 结果）。

## 文书

### SOP / PS

结构上回答四个问题，每段一个：

```text
1. 动机      你因为什么具体的事对这个方向感兴趣
2. 能力      你为此做了什么（课程、科研、实习），证明你有基础
3. 匹配      为什么是这个项目（具体到课程、实验室、导师）
4. 规划      你想研究什么，毕业后想做什么
```

几种典型写法问题：

- **通篇抒情**：说了很多热爱，没有一个具体事实
- **简历扩写**：把条目变成段落，没有新信息
- **模板化**：why school 段落套用，甚至写错学校名字
- **过长**：超出字数限制的部分不会被认真读

### CV

和推免用的简历基本一致，见[材料准备](/postgrad/materials)。
注意海外 CV 通常**不写照片、年龄、性别**。

### 推荐信

- 优先选**了解你**的老师，头衔是次要的
- 提前一个月沟通，提供 CV、SOP 和你想强调的点
- 确认老师是否能按时提交——多校多轮催办，越早越好
- 部分系统会向推荐人邮箱发送链接，提前确认邮箱可用
