# 申请时间线

按学期拆解，每个阶段标注"必须完成"和"最好完成"。

## 大二下：启动

这一年最重要的两个决定：**是否出国**、**读硕士还是博士**。

- [ ] 决定出国与否
- [ ] 开始背单词，熟悉 TOEFL/IELTS 题型
- [ ] 暑假尝试进课题组或找一份实习

这一步不要拖到大三。语言成绩有效期两年，大二下考的分数到申请季刚好还能用。

## 大三上：出分 + 攒经历

- [ ] 语言考试第一次（目标一次到位，但做好考两次的准备）
- [ ] 保持或提升 GPA，这一年权重最高
- [ ] 科研或实习有一段能写进 CV
- [ ] 如果目标是 PhD，开始接触海外老师的科研

## 大三下：选校 + 文书

- [ ] **语言成绩出分**（这是硬截止线，不能拖）
- [ ] 确定选校名单，按冲刺 / 匹配 / 保底分档
- [ ] 写 SOP / PS 初稿
- [ ] 确定推荐人，并当面说明你的规划

## 大三暑假：定稿

- [ ] SOP 定稿，逐校修改 why school 部分
- [ ] CV 定稿
- [ ] 推荐信全部沟通完成
- [ ] 语言最后冲刺（如果还没出分）

## 大四上：提交

| 月份 | 事项 |
| --- | --- |
| 9 月 | 网申系统开放，填基本信息，准备成绩单与在读证明 |
| 10 月 | 文书最后一轮修改，推荐信开始提交 |
| 11 月 | 集中提交 |
| 12 月 | 多数美国项目截止（常见 12 月中到 1 月初） |
| 1 月 | 剩余项目提交，检查材料齐全 |

> 截止日期各校差异很大，请以项目官网为准，并留出至少一周缓冲——
> 推荐人上传延迟是每年最常见的翻车原因。

## 大四下：结果与收尾

| 月份 | 事项 |
| --- | --- |
| 1-2 月 | 部分项目面试 |
| 3-4 月 | 录取结果集中发放 |
| 4 月中 | 美国项目普遍要求在此日期前决定去向 |
| 5-7 月 | 办签证、体检、租房、订机票 |
| 8 月 | 行前准备，选课与入学手续 |
