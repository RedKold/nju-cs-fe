# 语言考试

## 先确定考哪个

| 考试 | 适用 | 说明 |
| --- | --- | --- |
| TOEFL | 主要针对美国 | 全机考，听说读写各 30 分 |
| IELTS | 英联邦、中国香港、欧洲 | 分学术类 A 类，含口语面试 |
| GRE | 美国多数理工科项目 | 部分项目已改为可选，需逐校确认 |
| GMAT | 部分商科项目 | 计算机金融通常不需要 |

多数美国项目两个都接受，选一个考熟即可，不要同时准备。

## 分数目标

分数要求因项目档次差异很大，申请前务必查项目官网的明确要求，
以及往届录取的实际区间。

**待补充**：把你申请过的项目的最低要求和实际录取分数区间整理到这里，
这比笼统的"建议 100+"有用得多。

## 备考节奏

```text
第一阶段（2-3 个月）  背单词 + 熟悉题型，模考摸底
第二阶段（1-2 个月）  分项突破，阅读和听力先提分
第三阶段（1 个月）    口语写作模板化训练，整套模考
```

几条经验：

- **单词必须贯穿始终。** 断一周再捡起来成本很高。
- **写作和口语要开口、要动笔。** 只看范文不会提分。
- **模考用官方材料。** 第三方模拟题难度偏离大，容易误导。
- **早考早超生。** 大三上第一次，大三下留出重考机会，
  拖到申请季还在考语言是最痛苦的状态。

## 有效期

TOEFL 和 IELTS 成绩有效期通常为 **2 年**，需要在申请时仍然有效。
考得太早会过期，考得太晚来不及，大二下到大三上是比较合适的窗口。
