# 出国总览

出国申请是一场为期一年半的马拉松，难点不在某一项材料，
而在于**语言成绩、GPA、科研经历、文书**这几件事同时推进。

## 先想清楚三个问题

**读什么学位。** 计算机金融方向常见三类：

| 类型 | 说明 | 适合 |
| --- | --- | --- |
| MS / MSc | 授课型硕士，1～2 年 | 想尽快就业、转方向 |
| MFE | 金融工程硕士，偏量化 | 想做量化、衍生品定价 |
| PhD | 博士，5 年左右 | 想做研究、进高校或研究院 |

**去哪个地区。** 美国、英国、中国香港与新加坡、欧洲大陆，
在学制、费用、就业政策和申请时间上都不同，需要早做取舍。

**钱从哪来。** 硕士项目多数自费，博士通常有奖学金。
这是必须和家里摊开算清楚的一笔账。

## 时间线

完整节奏见[申请时间线](/abroad/timeline)，这里只给最粗的框架：

```text
大二下      决定是否出国，开始背单词
大三上      语言考试第一次，找科研或实习
大三下      语言出分，选校，开始写文书
大三暑假    文书定稿，确定推荐人，考最后的语言
大四上 9-12月 提交网申
大四下 1-4月  面试、收 offer、决定去向
大四下 5-7月  办签证、体检、订机票住宿
```
