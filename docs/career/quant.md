# 量化方向

量化是计算机金融最对口的出口，也是最看重硬实力的方向。

> ⚠️ **待补充**：本页的岗位分类是通用框架，欢迎补充国内外的实际招聘情况。

## 岗位类型

| 岗位 | 做什么 | 核心要求 |
| --- | --- | --- |
| 量化研究员 QR | 挖掘因子、建模信号 | 统计、机器学习、研究能力 |
| 量化开发 QD | 交易系统、数据管线、低延迟 | C++、系统、性能优化 |
| 交易员 Trader | 盯盘、执行与风险管理 | 反应速度、心理素质、市场直觉 |
| 风控 / 中台 | 风险建模、组合监控 | 统计、业务理解 |

## 技能栈

**数学与统计** —— 概率论、数理统计、时间序列、随机过程。
面试里问得最深的就是这一块。

**编程** —— Python 是研究岗主力，C++ 是开发岗主力。
要熟练到能处理真实数据，而不只是会写课程作业。

**数据** —— 会清洗、会对齐、知道幸存的偏差从哪来。
真实数据又脏又缺，这是课堂和实战差距最大的地方。

**金融直觉** —— 知道什么是套利、什么是风险敞口、
为什么一个回测看起来很美的策略实际会亏钱。

## 面试常见内容

- 概率题与脑筋急转弯（条件概率、期望、随机游走）
- 统计与机器学习基础（过拟合、偏差方差、常见模型）
- 编程题（算法与数据结构，部分岗位考 C++ 细节）
- 项目深挖（回测怎么做的、有没有考虑交易成本）
- 市场问题（对某个现象的看法）

## 准备建议

1. **先做一个完整的策略研究。** 从数据获取、因子构造、回测到评估，
   完整走一遍。这个项目会成为你面试时的主要谈资。
2. **把回测做诚实。** 考虑交易成本、滑点、幸存者偏差，
   面试官最常问的就是"你的回测有哪些问题"。
3. **刷概率题。** 这类题目有固定套路，提前练过和没练过差别很大。
4. **编程别只写 Python。** 目标岗位偏系统就练 C++，偏研究则练数据处理效率。
