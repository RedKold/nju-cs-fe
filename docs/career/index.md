# 实习与就业

计算机金融方向的出路大致分四类，准备方式差别很大。

| 方向 | 典型岗位 | 看重什么 |
| --- | --- | --- |
| [量化](/career/quant) | 量化研究员、量化开发、交易 | 数学、编程、数据处理 |
| 券商与投行 | 研究所、投行部、固收 | 财务、行业理解、沟通 |
| 互联网 | 算法、后端、数据 | 工程能力、项目经历 |
| 科研深造 | 读博、研究院 | 论文、科研训练 |

## 实习时间线

```text
大二暑假    第一份实习，门槛低一点也没关系，重点是"完整参与过"
大三寒假    部分暑期实习开始投递
大三下 3-5月 暑期实习集中投递与面试
大三暑假    暑期实习，这也是转正率最高的一次
大四        秋招 / 春招，或准备读研
```

## 怎么找

- **官网与公众号**：机构招聘公告，最权威
- **学长学姐内推**：成功率最高的渠道，不要不好意思开口
- **学校就业平台与宣讲会**：竞争相对小
- **开源项目与竞赛**：没有实习经历时，这是最好的替代品

## 准备什么

无论哪个方向，三样东西都要有：

1. **一份持续更新的简历**——和推免、出国共用一份即可
2. **一个能讲深讲透的项目**——不是罗列技术栈，而是能回答"为什么这么做"
3. **笔试能力**——算法题、数学题、专业知识，各方向侧重不同
