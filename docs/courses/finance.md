## 学习重点

**微观与宏观经济学** 的价值在于建立"激励—均衡—政策"的思考框架，
而不是记住结论。后面读研或做研究时，这套框架决定了你能不能提出问题。

**公司金融与投资学** 是估值和组合两条主干：前者回答"这个资产值多少钱"，
后者回答"该怎么配"。CAPM、有效前沿、风险收益权衡要能自己推一遍。

**计量经济学** 是技术含量最高、也最容易学成"套公式"的一门。
重点是理解 **内生性**：为什么回归系数不能直接解释成因果关系，
以及工具变量、双重差分这些方法各自在解决什么问题。

**衍生品与金融工程** 是计算机金融最核心的结合点：
二叉树、Black-Scholes、蒙特卡洛定价，都需要编程实现。

## 考核方式（常见形态）

- 理论课以期中期末的推导与简答为主
- 计量、衍生品一类课程通常有实证或编程作业，用 Stata / R / Python
- 部分课程有小组展示与论文报告

## 学习建议

1. **推导要自己走一遍。** 金融课的公式不难，难的是知道每个假设意味着什么。
2. **把计量当成工具课练手。** 找一个真实数据集，完整跑一遍从清洗到解释的过程。
3. **用代码复现模型。** 学完 Black-Scholes 就自己写一遍定价，
   比考试多考十分更有价值。
4. **关注市场。** 课上讲的事件在真实市场里长什么样，理解会深刻得多。
