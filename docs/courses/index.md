## 每门课建议记录什么

一门课的资料只有包含下面这些信息，对下一届才真正有用：

- **考核构成**：平时分、作业、期中考、期末考各占多少
- **重点章节**：哪几章必考、哪几章老师会跳过
- **往届真题**：年份和题型变化
- **踩坑点**：作业难在哪、实验环境怎么配、给分风格如何
- **推荐资料**：哪本教材或网课比指定教材讲得清楚

## 新增资料的命名规范

课件和真题统一按下面的格式命名，放在[资源区](/resources/)对应的表格里：

```text
课程名-资料类型-年份.后缀

例：
数理统计-期末真题-2024.pdf
数据结构-课件-2023秋.zip
计量经济学-复习提纲-2025.pdf
```
